# Tarkov Tracker
Escape from Tarkov is a game with thousands of individual items, each with their own prices, rarity, and uses. Tarkov Tracker aims to simplify this by giving users one place to search the database, compare item prices, and plan what items they need to look for.

To run the app locally, download the repo, run npm install, and run npm run dev in BOTH the client and server folders.

The app is hosted on Render at the following link:
https://tarkov-tracker-client.onrender.com/
